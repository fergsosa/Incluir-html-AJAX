# 📘 SPA Incluir html AJAX

Desarrollo de una Single Page Application (SPA) que utiliza HTML para la estructura y AJAX para una interacción dinámica y fluida. La aplicación cargará una única página web, y las actualizaciones de contenido se realizarán asíncronamente mediante AJAX, mejorando la experiencia del usuario al evitar recargas completas.

## 🛠️ Tecnologías utilizadas

- **HTML:** Para la estructura y el contenido de la interfaz de usuario.
- **JavaScript:** Para la lógica del lado del cliente, la manipulación del DOM y la implementación de las llamadas AJAX.
- **AJAX:** Para la comunicación asíncrona con el servidor (utilizando la API XMLHttpRequest o la función fetch de JavaScript).

## 👤 Experiencia de Usuario Mejorada

La combinación de la arquitectura SPA y AJAX proporcionará una experiencia de usuario ágil y responsiva, minimizando los tiempos de carga y ofreciendo una navegación intuitiva.

## 🎯 Objetivos del Proyecto

- Desarrollar una aplicación web con una interfaz de usuario moderna y atractiva.
- Optimizar la experiencia del usuario mediante transiciones fluidas y actualizaciones dinámicas del contenido.
- Implementar una comunicación eficiente con el servidor utilizando AJAX.
- Demostrar la efectividad de la arquitectura SPA para construir aplicaciones web interactivas.
